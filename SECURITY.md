# Security Policy

If you find a security problem in this tool itself (not in a project you scanned with it), please report it privately instead of opening a public GitHub issue.

**Contact:** [security@psylinksssecurity.com](mailto:security@psylinksssecurity.com)

Please include:
- What you found and where (file/line if possible)
- Steps to reproduce it
- What you think the impact is

We aim to acknowledge reports quickly and will credit researchers who report responsibly, unless you'd prefer to stay anonymous.

Please do not test this against systems or code you don't own or have permission to test.
