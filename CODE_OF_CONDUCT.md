# Code of Conduct

## Our standard

We want this project to be useful, respectful, and safe for everyone. Contributors must communicate professionally, assume good faith, welcome different experience levels, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, sexualized attention, deliberately exposing private information, and using this project to test systems without authorization.

## Enforcement

Project maintainers may remove or edit comments, close discussions, or restrict participation when behavior violates this standard. Report conduct concerns privately to [security@psylinksssecurity.com](mailto:security@psylinksssecurity.com).
