# PsyLinks 360° Security — Agent Instructions

When working on software in this repository, apply the PsyLinks 360° Security Review in [`SKILL.md`](./SKILL.md).

Use it proactively for authentication, APIs, backend services, databases, secrets, dependencies, payments, file uploads, deployment, security reviews, and AI-agent or MCP workflows. Read the relevant files under [`references/`](./references/) and run [`scripts/scan.py`](./scripts/scan.py) when reviewing code.

This file is a compatibility entry point for coding agents that support `AGENTS.md` but do not automatically discover Agent Skills. It is not a replacement for the complete skill instructions.
